# RatGame Ring Tiering Sheet

Editable working document for ring reward tiering.

## Tier Definitions

| Tier | Meaning |
|---|---|
| t0 | Chase. Build-defining, high wow factor, high synergy, or dramatic power spike. |
| t1 | Rare. Strong, exciting, or highly synergistic, but not always build-defining. |
| t2 | Uncommon. Good ring, meaningful direction, moderate synergy or power. |
| t3 | Common. Simple filler, low complexity, lower power, or early-run support. |

## Tiering Criteria

Tier rings by:

- Relative power / damage increase
- Wow effect
- Synergy potential
- Build-defining potential
- Defensive value
- Complexity / implementation cost
- How often the player should see it

# Implementation Readiness Ranking

Ranks are based on the current ring runtime, not on design desirability. Current systems support static `STAT_MODIFIERS`, `COMBAT_RULES`, `TRIGGERED` actions for player hit/kill/crit combat events, two hand effects, typed ring rewards, vendor offers, armor absorption, zones, projectile pierce, and projectile bounce internals. They do **not** currently support tiered ring authoring, family tags outside the V1 family list, timed buffs, block charges, enemy stun/slow as general status effects, reward reroll UI, conditional ring-position effects, or effect graphs that read neighboring rings.

## Already Implemented Baseline

These are already present in `RING_DEFS_V1` and are mostly useful as reference patterns for new authoring:

- Starter rings: Street Reflex, Lucky Chamber, Contaminated Rounds, Point Blank Carnage, Thermal Starter.

## Ready After Small System Upgrades

These fit current architecture, but need one focused primitive, stat key, trigger match, reward knob, or combat-rule consumer before content can be authored cleanly.

| Ease | Ring | Needed Upgrade | Why |

| 1 | Sharpened Tip | Add projectile-hit damage stat or accept global hit damage approximation. | Current stats have projectile count/speed/pierce but not projectile damage. |

| 3 | Close Quarters Guard | Add conditional combat rule for "no pierce" + proximity damage. | Proximity damage exists; pierce-count condition does not. |

| 8 | Ricochet Rounds | Add projectile bounce stat key and apply it during player weapon projectile spawn. | Bounce arrays already exist for projectiles; ring stats cannot grant bounces yet. |

## Suggested First Implementation Batch

For the next code pass, start with the `Ready to Implement With Current Systems` table, then the smallest upgrade cluster:

1. Content-only filler/enabler rings: Small Damage Band, Quick Step, Bruiser's Band, Dirty Needle, Small Spark, Lucky Scratch, Twitchy Mechanism, Minor Vitality.
2. Projectile stat expansion: Sharpened Tip, Ricochet Rounds, Scatter Shot refinement.
3. Reward manipulation: Wider Selection, Curated Rewards, Selective Hand.
4. Conditional combat rules: Close Quarters Guard, Pure Force, Physical Devotion.

The block family, mirror/amplify positioning rings, timed buffs, next-shot empower, and enemy crowd-control statuses should be treated as separate system design passes.

# Keyword Notes

## Empower

**Empower** modifies the next shot/attack from the player weapon.

Current empower examples:

| Ring | Effect |
|---|---|
| Heavy Chamber | Every 4 seconds, empower your next shot to deal 50% increased physical damage. |
| Kill Momentum | Killing an enemy empowers your next shot to deal 20% increased damage. |
